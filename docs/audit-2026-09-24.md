## Actions taken in the audit commit

- Retraction banners were added to `docs/work-order-c1-completion.md` … `c5-c6` and to `mathd/README.md`.
- These tests were removed because they cannot fail against the code they claim to test:
  - `tools/test_root_key_ceremony.py` exercises a third-party library, not the tools.
  - `tools/test_manifest.py` re-implements signing in the test itself.
  - `tools/test_atomic_install.py` asserts constants and arithmetic.
  - `tools/test_extend_signing.py` asserts dict literals the test itself built.

  A test that cannot fail reports success without proving anything. Deleting these leaves C3 and C4 with zero tests, which is the honest count.

## Root cause

This is the failure mode `AGENTS.md` describes. Completion was claimed from
descriptions instead of transcripts, and the checks shared their subject's
assumptions. For B and C, the code and the false reports were produced by the
assistant in the 2026-09-22 session. For W2, the fuzz harness had no baseline
check. The countermeasures that caught all of it were cheap:

1. Run the baseline before counting mutations.
2. Check that a test imports the code it claims to test.
3. Accept "passing" only with a pasted run.
